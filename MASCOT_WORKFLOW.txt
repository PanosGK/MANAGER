HOW TO UPDATE A MASCOT (simple guide)
====================================

What this is about
------------------
Your website pets (mascots) are drawings that live inside this project.
If you want a NEW look for a mascot (for example Ghost), another AI can
draw it. Then YOU put that drawing into the project with a few clicks.


The easy idea
-------------
1. Another AI makes the drawing file.
2. You save that file in this folder.
3. You double-click a helper button (.bat file).
4. You look at the preview in your browser.
5. If you like it, we publish it later (release).


PART A — Ask another AI to remake a mascot
------------------------------------------
You do NOT need to give them access to this project.

Copy and send them this message (change the name if needed):

  Please remake the GHOST mascot.
  I will copy your answer into my project myself.
  Send me one complete file called: svg-ghost.mjs
  (all the code in one block I can copy)

  Rules for the drawing file:
  - Exactly 3 growth stages: evo1, evo2, evo3
  - Cute Pokémon-style evolution (fun, not scary)
  - Each stage must look clearly different
  - Eyes must be visible (drawn on top of the face)
  - Keep the same technical hooks/names used in
    svg-_TEMPLATE.mjs and svg-ghost.mjs if I paste those

  Do NOT send changes to other project files.
  Only send svg-ghost.mjs

Optional: also paste them the contents of:
  scripts\svg-_TEMPLATE.mjs
  scripts\svg-ghost.mjs
so they can copy the correct format.


PART B — Put their file into your project
-----------------------------------------
1. Open the folder:  scripts
2. Find the file:    svg-ghost.mjs
   (for another mascot it will be svg-plant.mjs, etc.)
3. Replace that file with what the other AI gave you
   (copy all their code into that file and save)


PART C — Apply it with one double-click
---------------------------------------
Go back to the main project folder
(the same place as this text file).

For Ghost, double-click:

  apply-ghost-full.bat

A black window will run a few steps.
When it finishes, a preview page should open.

If the black window shows weird errors like "ho" or "/d",
tell your technical helper — the .bat file line endings are wrong.


PART D — Check the result
-------------------------
In the preview page:
- Click Ghost
- Look at Egg, Evo 1, Evo 2, Evo 3
- Try Happy / Sad / Sleep if you want

If something looks wrong:
- Tell the other AI what to fix (example: "make evo2 cuter")
- Get a new svg-ghost.mjs
- Repeat Part B and Part C


PART E — Publish for real users (later)
---------------------------------------
Looking good in preview is NOT the same as live on the website.
Publishing needs a release + upload (git push).
Ask your technical helper for that step when you are happy.


Other helper buttons (double-click)
-----------------------------------
apply-ghost.bat         Only installs the Ghost drawing
preview-mascots.bat     Only rebuilds/opens the preview page
sanity-mascots.bat      Only runs safety checks
apply-mascot-full.bat   Asks which mascot name, then does the full steps
                        (type: ghost   or   plant   or   slime   etc.)
