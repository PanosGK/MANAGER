What to add (keep it easy)

  1. 1
    Smarter search, same box

    One field understands 15 pro, barcode, and IMEI. Paste a code → jump straight to that unit. No extra toggles.

  2. 2
    Quiet guidance on cards

    Only when useful: “Τελευταίο τεμ.”, “Κοντύτερο: Γλυφάδα”, star for favorites. No filter toolbar of chips on the models step.

  3. 3
    Best row, not more columns

    Highlight the best available unit. Show IMEI under barcode on hover/focus. Keep the table at 6 familiar columns.

  4. 4
    Useful copy toast

    Confirm what was copied: model · grade · GB · color · barcode — ready to paste into chat.

  5. 5
    Network: one recommended store

    Sort by buyable + distance. Label “προτεινόμενο” once. Separate “περισσότερο stock” when different. Explain blocked BB in plain Greek.

  6. 6
    Keep filters across tabs (optional)

    If you filtered 256GB in your store, switching to network keeps it. Off by default; one setting in gear menu.

  7. 7
    Recent models

    Thin strip of last opened models. Daily muscle memory without a “dashboard”.

  8. 8
    Power tools stay in gear

    Tags, column prefs, export selected, scope (iPhone vs all) live in Settings — not on the main path.

What not to do (learned)

  1. ×
    No toggle strip on models

    Favorites / in-stock / buyable / keep-filters / all-devices as always-visible pills made the first screen feel like a control panel.

  2. ×
    No wider table by default

    IMEI + tags + title + checkboxes + sort headers at once = hard to scan on shop floor.

  3. ×
    No compare matrix upfront

    Useful later as an optional “Σύγκριση” action when filters are active — not dumped above every network view.

  4. ×
    No legend clutter on mine

    Purchase rules belong to network only. Mine stays Διαθέσιμο / BB.

Principle: every new pixel must either reduce a click, prevent a mistake, or answer a question staff already ask. If it only adds capability, put it behind gear or a long-press.
