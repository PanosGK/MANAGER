Τι δεν θα κάνω

Μάθημα από προηγούμενες προτάσεις — αυτά μένουν έξω.

  • Toggle strip στο πρώτο screen (favorites / in-stock / buyable / keep-filters)
  • Ευρύτερο table με IMEI + tags + checkboxes πάντα ορατά
  • Compare matrix πάνω από κάθε network view
  • Purchase legend στο δικό σας κατάστημα
  • Δύο κουμπιά Αντιγραφή / Άνοιγμα σε κάθε γραμμή
  • Emoji / pin icons που θολώνουν τα tabs

Επόμενο βήμα: πείτε μου στο chat «έγκριση» ή ποια checkboxes αλλάζετε / τι να διορθώσω στο mock. Μόνο τότε αγγίζω το live UI.
